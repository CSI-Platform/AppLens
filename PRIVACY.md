# Installed desktop privacy notice

Installed (the AppLens Windows client) collects PC specifications and installed
application information locally. A read-only scan starts when you open the app;
you can cancel it or start another scan. The scan does not change system settings.

Collected information includes Windows version, manufacturer/model, processor and
graphics names, memory and disk readings, installed app names/versions/publishers,
installation identities and locations, computer name and Windows username.
Optional workflow goals, services and constraints are text you supply. Do not
include passwords or access keys. The client does not collect credentials or run
the deferred AppLens-Tune diagnostics. It has no accounts, telemetry, automatic
uploads or background monitoring.

Reports include the complete captured inventory, optional notes and recorded
actions even when display filters hide rows. Known computer/user identifiers and
the current user's profile path are redacted by default; you may explicitly
include them. App names and notes can still contain sensitive information.

Download report writes a readable file only to a destination you select. Send
report first shows a review, then hands that report to Windows sharing. You choose
the sharing app and recipient; their handling of the report is subject to their
own practices. Installed does not choose a recipient or verify email delivery.
The app supplies a streamed attachment without writing an additional export file;
Windows and the selected sharing app may cache or retain the shared content.

Supported uninstall actions require separate confirmation. New action history is
protected for the current Windows user; older development history is preserved.
Exported/shared reports are readable and are not protected by that history
encryption. See the [full privacy draft](docs/AppLens-Privacy-Draft.md) for history
and retention limitations. The release requires a verified hosted policy and
contact details; this repository notice is not evidence of Store publication.
