# AppLens artwork

The AppLens*.png images and AppLens.ico are original geometric artwork created
for this project from the deterministic drawing in tools/New-AppLensAssets.ps1.
They use no external image, font file, stock asset or generated photograph.
Existing CSI placeholder artwork is retained separately.

The silver square and black angular A follow the approved client direction.
Owner review is still required before using the artwork in a public Store listing.
The generation script refuses to overwrite existing files.
